# Bluesky エージェントキット

あなたの AI エージェント（Claude Code など）がこのフォルダを読むと、Bluesky の**投稿・スレッド・返信**を毎日続けられるようになるキットです。

**費用は、Bluesky の API は無料（書き込みは1時間5000点・1日35000点まで。投稿1本3点）。** このキットはほかのサーバーに何も送りません。

---

## 最初の10分

1. このフォルダを自分のパソコンに置く（受け取ったリポジトリを clone する）
2. `python3 --version` で 3.11 以上か確かめる
3. `cp .env.example .env` → 下の「キーの取り方」でキーを入れる
4. コマンドは既定で「送る予定を表示するだけ」（dry-run）。**`--go` を付けたときだけ本当に動きます**
5. まず見るだけ（何も送られない）：
   ```
   python3 scripts/bsky_post.py --file drafts/example.md
   ```
6. `--go` を付けると本当に投稿：`python3 scripts/bsky_post.py --file drafts/example.md --go`
7. AI エージェントに「AGENT.md を読んで、今日の分をやって」

---

## キーの取り方

1. Bluesky アプリの設定 → プライバシーとセキュリティ → **アプリパスワード** を作る（本当のパスワードは使わない・アプリの表示名は変わることがあります）
2. `.env` に `BSKY_HANDLE`（例 yourname.bsky.social）と `BSKY_APP_PASSWORD`

---

## できること・できないこと（公式ドキュメントで確かめた範囲）

| やりたいこと | できるか | 道具 |
|---|---|---|
| 投稿・スレッド | できる（1投稿300字） | `bsky_post.py` |
| 返信・メンションの取得と返信 | できる | `bsky_notifications.py` |
| リンク | 本文のURLを自動でリンクにする | `bsky_post.py` |
| いいね数などの集計 | このキットでは集めない（アプリで見る） | ― |

- ログインは1アカウント5分30回・1日300回まで
- 自動フォロー・自動いいねは入れていない（迷惑行為の決まりに触れる）

## 道具

| 道具 | すること |
|---|---|
| `bsky_post.py` | 投稿・スレッド・返信（`--reply-to at://...`） |
| `bsky_notifications.py` | 返信・メンション集め → 下書き → 確かめたものだけ返信（1回20件まで） |

## 毎日の動かし方（cron の例）

```
0 8 * * * cd /path/to/bluesky-agent-kit && python3 scripts/bsky_notifications.py fetch --go >> data/cron.log 2>&1
```
`/path/to/` は自分の置き場所に替えてください。

## 中身

```
README.md / AGENT.md / CLAUDE.md
playbooks/   01 手順 ／ 02 ふり返り
templates/   下書き・アカウントの軸・ふり返りの型
scripts/     道具（Python 3.11 の標準ライブラリだけ）
drafts/      下書きの置き場
data/        記録の置き場（git に入れない）
```

## 困ったとき

| 出たもの | 意味 | やること |
|---|---|---|
| HTTP 401 | ハンドルかアプリパスワードが違う | `.env` を確かめる・アプリパスワードを作り直す |
| HTTP 429 | 呼びすぎ | 時間をあける |
| 300字を超えた | 長すぎ | `## 2投稿目` に分けてスレッドに |

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。

## 困ったとき・もっと伸ばしたいとき

分からない・動かない・時間がかかっている——そんなときは、ひとりで抱えないでください。
**N-Hack の受講生ページ／個別コンサルチャンネル**から、担当にそのまま相談できます。
あなた専用のAIと伴走しながら、最短で結果まで一緒に持っていきます。

このキットのAIは、あなたが詰まったときや区切りのときに、自分から相談先を案内します。
