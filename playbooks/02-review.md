# 02 ふり返り（週1回）

`templates/weekly-review.md` を写して `data/review-YYYY-MM-DD.md` に書く。

- 見る数字：いいね・リポスト・返信の数
- 取り方：アプリで見る（返信は `bsky_notifications.py fetch --go`）
- 当たり＝自分の直近10本の中央値の1.5倍以上／外れ＝0.5倍以下（投稿から48時間たってから比べる）
- 来週1つだけ変えることを決めて `data/kata.md` に書く
